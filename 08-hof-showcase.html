02 · Callbacks — funciones como argumentos

Patrones de Callback

Una función de orden superior acepta otra función como argumento. Así funcionan map, filter, sort y más.

sort() con callback

Ordena según la función de comparación que le pases.

[3,1,4,1,5].sort((a,b) => a-b)
// [1,1,3,4,5]

setTimeout(callback, ms)

Ejecuta la función después de N milisegundos.

setTimeout(() => console.log("¡Ya!"), 1000)

addEventListener(event, cb)

Llama al callback cuando ocurre el evento.

btn.addEventListener("click", () => { ... })

Función personalizada

Cualquier función puede aceptar un callback.

function apply(arr, fn) {
  return arr.map(fn);
}
