01 · Tres formas de declarar una función

Sintaxis comparada

En JavaScript hay varias formas de definir una función. Cada una tiene sus casos de uso.

Function Declaration

function sumar(a, b) { return a + b; } // Hoisting: disponible antes de declararse sumar(2, 3); // → 5

Function Expression

const sumar = function(a, b) { return a + b; }; // Sin hoisting — debe declararse antes sumar(2, 3); // → 5

Arrow Function

const sumar = (a, b) => a + b; // Sintaxis corta para funciones simples sumar(2, 3); // → 5

03 · Scope — Alcance de las variables

Global vs Function vs Block Scope

El scope determina dónde puede accederse a una variable. Visualiza el alcance de cada una.

Global Scope
const appName = "MiApp"; // accesible en todo
let usuario = "Edisson";
Function Scope
function saludar() {
  const mensaje = `Hola ${'{'}usuario{'}'}`; // solo aquí
  if (true) {
    let bloque = "solo en if"; // block scope
  }
  // bloque no accesible aquí
}
// mensaje no accesible aquí ❌
// appName sí accesible aquí ✅
