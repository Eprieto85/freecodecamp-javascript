01 · Hoisting — ¿Qué se eleva y qué no?

Orden de ejecución con Hoisting

JavaScript "eleva" declaraciones al inicio del scope antes de ejecutar el código. Pero no todas.

✅ Function Declaration — disponible antes de declararse
saludar(); // funciona ✓ function saludar() { return "hola"; }
❌ var — se eleva pero como undefined
console.log(x); // undefined (no error, pero no el valor) var x = "valor";
❌ let / const — zona muerta temporal
console.log(y); // ReferenceError ✗ let y = "valor";
❌ Function Expression — no se eleva
fn(); // TypeError: fn is not a function ✗ const fn = () => "hola";
