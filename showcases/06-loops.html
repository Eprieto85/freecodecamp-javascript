Ciclos en JavaScript

for, while, do...while, for...of y for...in — cuándo y cómo usar cada uno.

01 · Los cinco tipos de ciclo

Sintaxis y casos de uso

Cada ciclo tiene su momento ideal. Aquí puedes ver el código y el output de cada uno.

for (let i = 0; i < 5; i++) { console.log(i); } // 0, 1, 2, 3, 4 // Usar cuando conoces cuántas veces
let count = 0; while (count < 5) { console.log(count); count++; } // Usar cuando no sabes cuántas veces
let n = 0; do { console.log(n); n++; } while (n < 3); // Siempre ejecuta al menos una vez
const frutas = ["🍎", "🍊", "🍋"]; for (const fruta of frutas) { console.log(fruta); } // Ideal para arrays e iterables
const obj = { a:1, b:2, c:3 }; for (const key in obj) { console.log(key, obj[key]); } // Ideal para las claves de un objeto
