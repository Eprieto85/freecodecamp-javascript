01 · Tipos de declaración

const · let · var

Cada palabra clave tiene un comportamiento distinto respecto a reasignación, redeclaración y scope.

const

No se puede reasignar ni redeclarar. Scope de bloque.

Preferida
let

Se puede reasignar, no redeclarar. Scope de bloque.

Cuando cambia
var

Scope de función. Se puede reasignar y redeclarar. Obsoleta.
