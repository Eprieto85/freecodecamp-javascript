02 · Atributos ARIA — referencia rápida

Los ARIA más usados en JavaScript

Estos atributos comunican el estado dinámico de los componentes a los lectores de pantalla.

aria-expanded
Indica si un elemento colapsable está expandido o colapsado. Uso: menús, acordeones.
aria-live
Anuncia cambios dinámicos. Valores: polite (espera), assertive (interrumpe), off.
aria-selected
Estado de selección en tabs, opciones de lista o tree items.
aria-disabled
Indica que un elemento está deshabilitado sin quitarlo del flujo del DOM.
aria-haspopup
Indica que el elemento abre un menú, listbox, tree o dialog.
aria-controls
Vincula un control con el elemento que controla por ID.
aria-label
Texto accesible para elementos sin label visible.
aria-labelledby
Apunta al ID de un elemento existente como label.
