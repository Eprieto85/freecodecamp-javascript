03 · Desestructuración de objetos y arrays

Sintaxis de Destructuring

La desestructuración extrae valores de objetos y arrays en variables de forma concisa.

Objeto
const persona = { nombre: "Edisson", ciudad: "Bogotá", edad: 30 }; // Desestructuración const { nombre, ciudad } = persona; // nombre → "Edisson" // ciudad → "Bogotá" // Con alias const { nombre: n } = persona; // n → "Edisson"
Array
const colores = [ "rojo", "verde", "azul" ]; // Desestructuración const [primero, , tercero] = colores; // primero → "rojo" // tercero → "azul" // Rest operator const [head, ...rest] = colores; // rest → ["verde","azul"]
