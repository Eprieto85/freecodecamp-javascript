02 · Tipos comunes de errores en JavaScript

Explorador de Errores

Haz clic en cada tipo de error para ver un ejemplo de código y su explicación.

// ❌ Error: falta coma entre elementos const arr = ["Beau", "Quincy" "Tom"]; // SyntaxError: Unexpected string // ✅ Correcto const arr = ["Beau", "Quincy", "Tom"];
SyntaxError — Ocurre cuando escribes algo gramaticalmente incorrecto en tu código. Como un error de ortografía en el lenguaje JavaScript. El motor no puede ni leer el código.
// ❌ Error: variable no definida console.log(price); // ReferenceError: price is not defined // ✅ Correcto const price = 19.99; console.log(price); // 19.99
ReferenceError — Se produce al intentar usar una variable que no existe, o al acceder a una variable let/const antes de declararla (zona muerta temporal).
// ❌ Error: operación en tipo incorrecto const obj = { name: "Jessica" }; obj.map(); // TypeError: obj.map is not a function // ✅ Correcto — map es de arrays const arr = [1, 2, 3]; arr.map(x => x * 2); // [2, 4, 6]
TypeError — Ocurre al realizar una operación en un tipo de dato incorrecto: llamar algo que no es función, acceder a propiedad de null, etc.
// ❌ Error: valor fuera del rango válido const arr = []; arr.length = -1; // RangeError: Invalid array length // ✅ Correcto const arr = []; arr.length = 5; // válido
RangeError — Sucede cuando un valor está fuera del rango que JavaScript acepta: longitud negativa, demasiada recursión, número de decimales inválido, etc.
